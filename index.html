① วิธีสร้างตารางด้วย Gemini

1. Copy prompt ด้านล่าง
2. เปิด Gemini → วาง prompt + แนบรูป/ไฟล์ใบเสร็จ
3. Gemini ส่ง output เป็นตาราง COL1–COL10 เว้น COL7–COL10 ว่างไว้
4. กรอก COL7–COL10 → save เป็น .xlsx
5. อัพโหลดใน Tab ui.vision Macro เพื่อ generate JSON

📋 Prompt สำหรับ Gemini
อ่านใบเสร็จที่แนบมาทั้งหมด แล้วสร้างตาราง Excel สำหรับ eClaims ให้ฉัน โดยให้มี 10 คอลัมน์ดังนี้: - COL1: ชื่อร้าน/vendor (จากใบเสร็จ) - COL2: วันที่ในรูปแบบ DD-Mon-YYYY โดย YYYY คือปี ค.ศ. เท่านั้น (ไม่ใช่ พ.ศ.) เช่น 22-May-2026 ถ้าใบเสร็จระบุ 22/05/2569 ให้แปลงเป็น 22-May-2026 - COL3: เลขที่ใบเสร็จ หรือ เลขที่ใบกำกับภาษี (จากใบเสร็จ)ถ้าหาไม่พบให้ใส่ "N/A" - COL4: จำนวนเงินรวม VAT ทั้งสิ้น (Grand Total / จำนวนเงินรวมทั้งสิ้น) ใช้ตัวเลขทศนิยม 2 ตำแหน่ง ห้ามมี comma เช่น 4360.00 (ไม่ใช่ 4,360.00) - COL5: ประเภทรายการ เช่น อาหารและเครื่องดื่ม / ค่าบริการกอล์ฟ / ค่าแคดดี้ - COL6: ชื่อเขต/อำเภอที่ตั้งร้านเท่านั้น ไม่ต้องใส่จังหวัด (ดูจากที่อยู่ร้านในใบเสร็จ) - COL7: Company Name of Client → เว้นว่างไว้ - COL8: Name & designation of Person(s) → เว้นว่างไว้ - COL9: Number of Person(s) → เว้นว่างไว้ - COL10: Description → เว้นว่างไว้ กฎสำคัญ: 1. ใบเสร็จแต่ละใบ = 1 แถว 2. ถ้าร้านเดียวกัน วันเดียวกัน มีทั้งใบกำกับภาษี (Tax Invoice) และใบรายการอาหาร (Itemized bill) → นับเป็น 1 แถว ใช้ใบกำกับภาษีเป็น primary เท่านั้น 3. COL4 ต้องเป็น Grand Total รวม VAT แล้ว ไม่ใช่ยอดก่อน VAT 4. COL4 ห้ามมี comma ในตัวเลข 5. COL2 ต้องเป็นปี ค.ศ. เสมอ แสดงผลเป็น Markdown table พร้อมใช้งาน
② หลังได้ตารางจาก Gemini

กรอก COL7–COL10 เพิ่มเติม → save เป็น .xlsx → อัพโหลดใน Tab ui.vision Macro เพื่อ generate JSON ได้เลย
